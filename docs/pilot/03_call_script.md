# 電話與訊息腳本(給營運人員)

> 這是**建議話術**,用你自己的口氣改。重點是每一條「一定要說」和「一定不要說」。
> ⚠ 標 ⚠ 的句子**只有在對應的事情是真的之後才能說**(例如法務審閱)。

## 打之前

1. 打開 [02_candidates.md](02_candidates.md) 該店那一段:地址、電話、**我們現有的第三方資料**(通話時要請他確認哪些)。
2. **只在營業時間內、非用餐尖峰**打(10:00–11:00、14:00–16:30 通常比較有空)。
3. 候選名單標「⚠ 手機號碼」的:可能是老闆個人手機。只打一次,說明來意;對方說不要再打就**記下來、不再打**。不要把號碼貼到任何公開或群組裡。
4. 手邊開著 `/ops/claims`(邀請與驗證)與 [03b_pilot_log_template.csv](03b_pilot_log_template.csv)。

## 通話(約 5–8 分鐘)

**1. 開場(20 秒)**
> 「您好,我是〇〇,我們在做一個叫『揪呷』的聚餐小工具,幫多人聚餐時避開有人不能吃的東西。請問是〇〇〔店名〕嗎?方便佔用您幾分鐘嗎?」

不方便 → 問什麼時候打,記下,結束。

**2. 確認對方身分(只問職稱,不問姓名)**
> 「請問您是老闆或店長嗎?」

只有老闆 / 店長 / 能代表店家回答菜單的人才繼續。員工不確定 → 請他幫忙轉告、約個時間打給負責人。**職稱記下來,姓名不要記。**

**3. 說明在做什麼(重點都要說到)**
- 「我們會請您回答:菜單裡有沒有用到花生、堅果、蛋、牛奶這類常見過敏原,還有牛肉、豬肉、海鮮、素食這類項目,一共 19 題(最後兩題是:能不能帶寵物、親子友善)。**不確定就選『我不確定』,這是完全正常的答案**,不會有任何影響。」
- 「用餐的人看到的會是:**『店家於某月某日聲明目前菜單未使用花生』**這樣一句有日期的話。這是店家的聲明,**不是認證,也不是保證**。」
- 「對共用的鍋子、炸油、砧板,我們也會問是不是有共用。這題不確定也請直接選不確定,不要為了好看選『確認沒有共用』。」
- 「資料 90 天到期。菜單有改的話請跟我們說,**我們可以馬上撤下**,您也可以重新填。」
- 「我們不收費。」

**4. 一定要老實說的(店家常會問)**
- 「會不會帶來更多客人?」→ **「我們不保證。這個資料不會讓您排得比較前面,也不是廣告。它是讓有過敏或飲食限制的人,知道您店裡的實際狀況。」**(設計原則 D5、D6,不要為了說服店家而改口。)
- 「填錯了會怎樣?」→ 「所以不確定請選不確定。如果之後發現有誤,我們會先撤下聲明、跟您確認。」
- 「這是法律文件嗎?」→ 「這是您對自己菜單的說明。」⚠ **「切結內容我們請法律專業人士看過」這句,只有在法務真的核准之後才能說;沒核准就不要說,也不要開始邀請真實店家。**
- 「你們會怎麼用我的資料?」→ 「只用在這個工具,顯示給聚餐的人。我們不記您的姓名,只記職稱、驗證日期和方式。」

**5. 同意嗎?**
> 「您願意試試看嗎?」

- **拒絕 → 謝謝、結束。記『拒絕』、不要再追。** 不要勸、不要第二次打。
- 猶豫 → 「那我之後再跟您確認也可以」,記『之後再說』,**最多再聯絡一次**。

**6. 驗證(這通電話本身就是驗證)**
我們撥的是公開資料上的店家電話,**接電話的人自稱是老闆 / 店長,並確認能代表店家回答菜單** → 這就是「電話回撥」(`phone_callback`)。
- 當場在 `/ops/claims` 邀請這家店(**不要勾「示範用認領」**)→ **複製連結(只顯示一次)** → 按「驗證」→ 方式選「電話回撥」→ 對方身分選老闆 / 店長 → 備註寫:例如「撥打公開電話,老闆接聽,口頭確認可代表店家回答菜單」(**職稱,不要姓名或個人電話**)。
- 如果對方不是從公開電話接聽(例如你打手機、或對方轉給別人)→ 照實在備註寫,**不要為了方便寫成電話回撥**;不確定就不要驗證,改實地確認。

**7. 傳連結**
> 「我把專屬連結傳給您,用手機點開就能填,大概 5–10 分鐘。您想用 LINE 還是簡訊收?」

- 連結是**這家店專屬的**,請對方**不要轉傳**;30 天內有效。
- 對方給的 LINE / 手機**只用來傳這一次連結,不要存進任何地方**(資料庫、試算表都不要)。
- 一定要**在驗證完成之後**才傳連結。

**8. 結尾**
> 「填完送出後,我們會看過再發布,發布後會跟您說。不一定當天,我們會盡快。」

**不要承諾審核時限**。

## 訊息範本

**傳連結(LINE / 簡訊)**
> 【揪呷】剛才電話中說明的菜單聲明連結:{連結}
> 這是 {店名} 專屬的連結,請不要轉傳,30 天內有效。用手機打開就能填;不確定的題目請選「我不確定」。有任何問題直接回覆這則訊息或回電給我。

**審核通過、已發布**
> 【揪呷】{店名} 的菜單聲明已經發布(店家於 {日期} 聲明)。有效期限 90 天,到 {到期日}。菜單有改請隨時告訴我,我們可以馬上撤下或請您重新填寫。謝謝您的協助!

**退回補件**
> 【揪呷】{店名} 的聲明我們看過了,想再跟您確認:{具體問題,例如「花生這題您選了『完全沒有』,但網路上有人提到 土豆粽,請問是否有這項?」}。確認後您可以直接用原連結修改再送出。

**駁回**(盡量先電話溝通)
> 【揪呷】謝謝您的協助。{店名} 這次的聲明我們暫時沒有發布,原因是:{原因}。如果有疑問歡迎回電,之後也可以重新填寫。

**到期前提醒(第 75 天,手動)**
> 【揪呷】{店名} 的菜單聲明將在 {到期日} 到期。菜單有改嗎?如果沒有改,請回覆「沒有改」,我們協助您續期;有改請告訴我們,我們請您重新填寫。

## 共用設備那一題,怎麼向店家解釋

不要預設答案,也不要催促選「確認沒有共用」。可以這樣說明:

> 「這題問的是:做不含花生的餐點時,鍋子、炸油、烤盤、砧板、手套這些,有沒有跟含花生的餐點共用?
> 沒有共用,而且您很確定 → 『確認沒有共用』。
> 可能有共用,或看廚房怎麼出餐 → 『可能有共用』。
> 確定有共用 → 『確定有共用』。
> 不知道 → 『我不確定』。」

注意:答「可能」或「不確定」,對過敏的用餐者就**不會**顯示為已確認(只會顯示「店家聲明菜單未使用,但共用設備可能 / 未知」)——這是設計,不是店家做錯。這題的答案分布就是試辦假設 H2。

## 絕對不要說

- 「安全」「保證」「100%」「無過敏原」「零過敏」(系統自己也禁止這些字,店家聽到你說也會跟著說)。
- 「會讓您排在前面」「會帶來客人」「是免費廣告」。
- 「很簡單,隨便填就好」——填錯對過敏的人有實際後果。
- 「這只是形式」「不用擔心責任」——你不能替法律下結論。
